# Riyaz Walikar — Portfolio

Responsive, single-page static website, built from the supplied professional profile PDF.

## Deploy to Vercel

1. Upload this directory to a Git repository.
2. Import the repository into Vercel.
3. Choose **Other** as the framework preset, leave the build command empty, and deploy.

Alternatively run `npx vercel --prod` inside this directory.

There are no build dependencies. `index.html` is the complete site; fonts are loaded from Google Fonts with system fallbacks.

## Customize

Edit the copy and CSS variables at the top of `index.html`. Add a custom domain in Vercel's project settings.
